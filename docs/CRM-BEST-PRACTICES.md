# CRM Best Practices Built Into Launchpad CRM

1. **6-Stage Linear Pipeline:** `Cold` → `Warm / Inbound` → `Offer / Pay Link Sent` → `Active Student (Paid)` → `Graduated / Alumni` → `Closed Lost / Nurture`.
2. **Fit + Behavioral Lead Scoring (0–100):** Combines decision-maker status, offer value, and high-intent source (`free-help-request`, `inbound-form`, `scorecard`, `referral`) with engagement signals (`viewedDeck`, `replied`, `offer`, `deposit`).
3. **Deal Rot Alerts (>7 Days):** Flags warm/offer prospects with zero touchpoints for 7+ days so deals get a Day 5/9 check-in instead of dying silently.
4. **Closed-Lost Reason Capture:** Records why deals didn't convert so pricing/timing objections feed back into offers.
5. **360° Student Intake Context:** Stores skill level, OS, AI tools, pain points, live deploy links, and arbitrary Google Form answers so every live cohort or 1-on-1 feels hyper-personalized.
6. **Alumni Continuity Loop:** Tracks testimonials, bonus unlocks, 48-hour 1-on-1 upgrades, and B2B team referrals right inside the Student & Alumni lifecycle.
